# Собрать самостоятельно

Для запуска готового релиза эти инструменты не нужны.

## Приложение

Нужны Windows x64, Visual Studio 2022 Build Tools с инструментами C++ для рабочего стола и Windows SDK, а также CMake 3.24 или новее.

Из корня проекта в PowerShell:

```powershell
.\scripts\build.ps1 -AppOnly
```

Готовое приложение появится в `dist\WindowsGoodView.exe`. Внутреннее имя проекта и EXE сохраняется для совместимости с существующими профилями. Скрипт сам находит MSVC и SDK. Если заголовков WebView2 ещё нет, скачивается закреплённый пакет Microsoft и сверяется его контрольная сумма. Для первого получения SDK нужен интернет.

`-BuildOnly` оставляет результат в `build\native` без копирования в `dist`. Без `-AppOnly` также собираются отдельные тестовые программы. Тесты запускаются явно:

```powershell
.\scripts\build.ps1 -Test
```

Сценарии управления окнами и замеры анимации выделены в `-TestDesktop` и `-TestPerformance`. Они могут взаимодействовать с рабочим столом; для обычной сборки запускать их не требуется.

## Установщик

Дополнительно нужен Inno Setup 6.7 или новее. После сборки приложения:

```powershell
.\scripts\package.ps1 -SkipBuild
```

Скрипт создаёт установщик в `dist`. При первом запуске может понадобиться интернет для получения официального WebView2 bootstrapper. Его подпись Microsoft проверяется перед упаковкой.

## Шрифты и значки

Готовые статические шрифты и сгенерированные векторные контуры уже включены в исходники. Для обычной сборки Python и fontTools не нужны.

Для их повторной генерации доступны `scripts/prepare_fonts.py` и `scripts/prepare_glyph_paths.py`; они используют fontTools 4.60.1. Исходные переменные шрифты и четыре SVG хранятся в `third_party/fonts` и `third_party/lucide`. Лицензии находятся в `resources`.
