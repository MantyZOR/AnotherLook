# Фоновые приложения и системные команды

## Как находятся значки

Another Look использует несколько источников без списка поддерживаемых программ:

1. Получает новые уведомления `Shell_NotifyIcon` и запросы пересоздать значки после `TaskbarCreated`.
2. При запуске и раскрытии панели читает уже существующие значки из основного трея Explorer и его скрытой области. Это нужно для программ, которые не реагируют на запрос пересоздания значка.
3. Если классическая панель недоступна, пробует получить элементы и их действия через Windows UI Automation. Такое представление встречается в новых версиях Windows 11.

Для классических значков сохраняются идентификатор, версия протокола, изображение и адрес обратного вызова. Поэтому нажатие передаётся самой программе, а ПКМ вызывает её собственное меню. Переключение пользователя на Windows и выход из оболочки возвращают стандартные панели.

Импорт работает по запросу, без таймера постоянного обхода. Количество элементов ограничено 128; для чужих окон используются таймауты. Проверяются процесс Explorer, владельцы окон и формат данных. Временный буфер в Explorer освобождается после чтения; DLL не внедряется, настройки скрытия значков Windows не меняются.

## Где есть ограничения

У Windows нет общего документированного метода перечислить все значки чужого трея. Раскладка классического Explorer зависит от версии системы; она проверяется перед использованием. UI Automation зависит от того, какие элементы и действия предоставляет конкретная версия Explorer. В этом резервном режиме значок может отображаться общим символом приложения.

Поэтому обещать отображение абсолютно любого значка на любой версии Windows было бы неверно. Программа, которая сама пометила свой значок скрытым через `NIS_HIDDEN`, остаётся скрытой. Это отличается от значка, просто перенесённого Windows в скрытую область: такие значки импортируются.

## Сеть и USB

Справа от значков находятся отдельные кнопки Wi-Fi и USB. Они доступны независимо от наличия соответствующих системных значков.

Список Wi-Fi запрашивается при открытии меню через Native Wi-Fi API. Подключение использует сохранённые профили Windows; пароли Another Look не хранит. Для неизвестной сети открываются системные настройки. Успешное принятие запроса подключения ещё не означает, что сеть уже подключена: это определяет Windows.

USB-меню перечисляет подключённые USB-накопители, в том числе устройства, определяемые как фиксированные диски. Буквы томов объединяются по извлекаемому устройству. Извлечение идёт через `CM_Request_Device_EjectW`, без принудительного отключения. Если Windows запрещает извлечение, оболочка сообщает об этом.

## Win и панель питания

Панель появляется по одиночной Win только при включённом пространстве. Повторная Win или Escape закрывает её. Настроить положение, ориентацию и углы можно в «Расположение → Питание». Обычные приложения сворачиваются, оставаясь доступными на панели окон. Выключение, перезагрузка и сон требуют отдельного подтверждения.

Сочетания Win+E, Win+L и другие передаются Windows. Синтетический ввод может блокироваться при активном приложении с правами администратора: при таком отказе физическое отпускание Win больше не пропускается в «Пуск», а повторяется после возврата фокуса оболочке. Ограничения UIPI и защищённого рабочего стола сохраняются; `uiAccess` и системные политики оболочка не меняет. Поведение поверх повышенных приложений нужно проверять на конкретной системе.
