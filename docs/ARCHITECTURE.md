# Как устроен Another Look

Оболочка — обычное приложение поверх работающей Windows. Оно создаёт своё полотно и панели на каждом мониторе, управляет видимостью окон и хранит настройки пространств.

| Часть | Где находится | За что отвечает |
| --- | --- | --- |
| Пространства и настройки | `src/core.*`, `src/scene_actions.cpp`, `src/profile.cpp` | Карточки, оформление, позиции, сохранение профиля |
| Полотно и панели | `src/ui.*`, `src/surface.cpp`, `src/desktop_paint.cpp` | Окна оболочки и отрисовка |
| Кольцо окон | `src/orbit.cpp`, `src/orbit_raster.cpp`, `src/orbit_layout.h` | Сегменты, прокрутка, наведение и выбор окна |
| Появление окон и меню | `src/window_motion.*`, `src/branch_menu.*` | Общий переход окон, компактные меню, готовые изображения действий и короткие таймеры |
| Виджеты | `src/widgets.cpp`, `src/system_load.cpp` | Заметки, часы, календарь и общие образцы нагрузки системы |
| Программы и файлы | `src/launcher.cpp`, `src/app_index.cpp`, `src/file_index.cpp`, `src/ntfs*` | Поиск, каталог программ, дисковая база и чтение NTFS |
| Фоновые приложения | `src/tray.*`, `src/tray_import.cpp`, `src/tray_system.cpp` | Значки системного трея и передача команд программам |
| Сайты | `src/web.*` | WebView2, снимки страниц, остановка и выгрузка скрытых карточек |
| Панель питания | `src/power.cpp` | Возврат на полотно, расположение панели и подтверждение системных команд |
| Работа с Windows | `src/platform.*` | Окна, мониторы, системные панели и помощник восстановления |
| Временная замена Explorer | `src/explorer_session.*`, `src/explorer_ui.cpp` | Транзакция переключения, штатная остановка выбранного Explorer, возврат и сохранение состояния восстановления |

Для интерфейса используются Win32, Direct2D и DirectWrite. Небольшие прозрачные панели переиспользуют собственные BGRA-буферы. Шрифты встроены в EXE, графика значков хранится в векторных контурах.

Большая часть синхронизации идёт по событиям Windows. Измерение нагрузки, часы с секундами и движение фона включают таймеры только в нужных состояниях. Кольцо переиспользует одну геометрию дуги; короткие переходы прокрутки и наведения используют один таймер.

Файловый индекс хранится в SQLite. Для полного NTFS-тома отдельный повышенный помощник читает MFT; USN и уведомления Windows помогают обновлять изменения. Для остальных случаев используется перечисление каталогов. Каталог программ хранится отдельно.

В сборке разделены рабочий EXE и `goodview_ui_tests.exe`. Они используют общие объектные файлы интерфейса, но тестовые окна и сценарии не входят в приложение. В опубликованную переносимую сборку тестовый драйвер не включён.

Импорт существующих значков выполняется при запуске и раскрытии трея. Классический Explorer читается с проверками и таймаутами; UI Automation служит запасным источником. Сеть и USB запрашиваются при открытии собственного меню. Постоянного опроса этих источников нет. [Подробности и ограничения](TRAY_COMPATIBILITY.md).

Необязательная диагностика `src/live_probe.*` включается командой `--profile-ui` для работающего экземпляра и сама останавливается через 30 секунд. Обычный запуск не создаёт диагностический таймер и отчёт. Отдельный `scripts/measure-live.ps1` пассивно сопоставляет CPU процесса с положением указателя над окном кольца. [Методика](LIVE_PERFORMANCE.md).
