# Отрисовка при движении указателя

В 0.8.13 уменьшена работа на каждом кадре, без снижения частоты таймеров фона и кольца.

Запрос палитры раньше неявно копировал активное пространство, включая содержимое карточек: одна ветка условного выражения возвращала ссылку, а другая создавала временный `Scene`. Теперь сохраняются только три параметра цвета. Изменения темы, фона и акцента сразу пересчитывают палитру.

Граф один раз определяет подсвеченные узлы за кадр. Для неподвижной сцены не вызывается расчёт движения. Известная область обновления используется и для отсечения команд рисования. Свечение хранится в двух маленьких текстурах: вместе 32 КиБ на экран при 96 DPI, максимум 128 КиБ при высоком DPI. Они освобождаются вместе с ресурсами поверхности; копии всего монитора не создаются.

У кольца подготовлен заполненный контур сегмента. Кадр не копирует пути процессов и другие лишние поля описаний окон. События указателя меняют цель анимации, а таймер с прежним интервалом 16 мс выдаёт кадры. События показа собственных подсказок исключены из пути перечисления внешних программ; смена переднего плана продолжает обрабатываться.

## Короткий контрольный замер

Скрытый программный рендерер Direct2D, фон 1920 × 1200, 12 заметок в пространстве. Для каждого варианта фона выполнено 120 кадров с одинаковой последовательностью положений курсора. У кольца 18 тестовых окон, 9 видимых сегментов и 240 кадров. Все тестовые окна скрыты; перехват ввода, управление фокусом и замена панели задач не используются.

| Сценарий | До, мс CPU на кадр | После, мс CPU на кадр |
| --- | ---: | ---: |
| Связи ближайшего узла | 2,60 | 0,91 |
| Подсветка вокруг указателя | 4,30 | 2,34 |
| Отрисовка кольца | 1,50 | 1,37 |

Это пример одного короткого прогона, а не обещание процента CPU в диспетчере задач. CPU учитывает потоки самого тестового процесса. Скрытый тест не измеряет композицию рабочего стола, нагрузку остальных приложений, два реальных монитора или стоимость полного интерфейса с живыми сайтами. Сокращение числа кадров от событий мыши и лишних обходов окон в таблицу стоимости одного кадра не включено.

После последовательности частичных обновлений оба варианта фона побитово совпали с полной перерисовкой того же состояния. Проверены девять сочетаний темы и акцента, фильтрация собственных событий показа с сохранением событий фокуса. Сравнение с исходными изображениями показало отклонение каналов фона не более 2 из 255 из-за переиспользования свечения; прозрачность сохранена.

Исходник замера — `tests/pointer_cost.cpp`. Он собирается отдельно и не включается в рабочий EXE или установщик. В уже настроенной сборочной среде:

```powershell
cmake --build build/native --target goodview_pointer_cost
ctest --test-dir build/native -R '^pointer_render_cost$' --output-on-failure
```

JSON и контрольные изображения сохраняются в `build/native/pointer-cost/`. База файлового индекса пользователя не открывается.
